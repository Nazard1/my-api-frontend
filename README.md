# Клювання — фронтенд каталогу товарів

Проста сторінка, яка показує таблицю товарів (назва, бренд, категорія, ціна, залишок) з REST API інтернет-магазину «Клювання». HTML + CSS + jQuery (з CDN), без збирання й залежностей.

Бекенд: [Nazard1/my-api-project](https://github.com/Nazard1/my-api-project).

## Як запустити проєкт

1. Запустіть бекенд за інструкцією в його README (розділ «Як запустити проєкт»): [github.com/Nazard1/my-api-project](https://github.com/Nazard1/my-api-project). Бекенд має працювати на http://127.0.0.1:8000.
2. В окремому терміналі клонуйте фронтенд і запустіть статичний сервер у його папці (потрібен Python):

   ```powershell
   git clone https://github.com/Nazard1/my-api-frontend.git
   cd my-api-frontend
   python -m http.server 5500 --bind 127.0.0.1
   ```

3. Відкрийте http://127.0.0.1:5500.

Якщо бекенд не запущено, сторінка покаже повідомлення «Не вдалося отримати дані з API…».

| Що | Адреса | Порт |
| --- | --- | --- |
| Фронтенд | http://127.0.0.1:5500 | 5500 |
| Бекенд | http://127.0.0.1:8000 | 8000 |
| API | http://127.0.0.1:8000/api/v1/ | 8000 |

## Навіщо CORS

Фронтенд (`http://127.0.0.1:5500`) і бекенд (`http://127.0.0.1:8000`) працюють на різних портах, тобто це різні origin. Браузер за замовчуванням не дає сторінці читати відповіді з іншого origin (політика same-origin), тому бекенд має явно дозволити цей доступ заголовком `Access-Control-Allow-Origin`. У бекенді це робить `django-cors-headers`, а дозволені адреси задаються змінною `CORS_ALLOWED_ORIGINS` у файлі `.env`. Адреса фронтенду має бути в цьому списку (за замовчуванням там уже є `http://127.0.0.1:5500` і `http://localhost:5500`), інакше браузер заблокує відповідь і сторінка покаже повідомлення про помилку.
